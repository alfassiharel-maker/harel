================================================================================================
EMPIRICAL INSIGHTS
================================================================================================

1. Fidelity. 6/6 rows round-tripped byte-for-byte under SHA-256.

2. A single real file yields almost nothing. Best -0.07% (project source (concatenated)).
   Plain gzip beats BitEngine on 1/1 single files.
   Expected: one file has no second version, so there is no delta to take.
   This is the same result FINDINGS.md section 1 recorded for model weights.

3. Version pairs are where it works. Best 78.93% (4ed0f2d..19a114e), 5/5 pairs above 1%.
   BitEngine beats large-dictionary LZMA on ratio in 1/5 pairs.
   BitEngine alone beats plain gzip on 1/5 pairs.

4. BitEngine THEN gzip is the strongest configuration: better than gzip alone on
   4/5 pairs, best 95.49% (4ed0f2d..19a114e).
   They are complementary: the delta removes long-range duplication gzip's 32KB
   window cannot reach, gzip entropy-codes the residual the delta leaves alone.
   Against large-dictionary LZMA, the strongest baseline available here:
   BitEngine+gzip wins 3/5 pairs.
     4ed0f2d..19a114e      95.49%  vs LZMA  78.67%  (+16.82 pts)
     fcba153..21df2f8      93.24%  vs LZMA  78.70%  (+14.54 pts)
     19a114e..fcba153      93.03%  vs LZMA  78.68%  (+14.35 pts)
   Where it loses, the 'pair' was not a pair: those revisions added a whole new
   directory, so most of the second file has no counterpart in the first.

5. Throughput. Encode 30-35 MB/s, decode 198-343 MB/s, single-threaded pure Python.
